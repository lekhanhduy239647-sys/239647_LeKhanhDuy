# Hệ thống quản lý nhân sự

- Họ tên: Lê Khánh Duy
- MSSV: 239647
- Lớp: TÊN LỚP

Mô tả: ứng dụng quản lý hồ sơ nhân viên (xem, thêm, tìm kiếm, sửa, xóa).

Công nghệ: React, Node.js/Express, MongoDB Atlas, Docker, Docker Hub, Render.

## Chạy ở môi trường phát triển
1. `cd backend && cp .env.example .env` (điền MONGODB_URI) rồi `npm install && npm start`
2. `cd frontend && npm install && npm run dev`
